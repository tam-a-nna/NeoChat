\# NeoChat - Modern LAN Chat System



A feature-rich, real-time LAN chat application with admin panel and modern UI.



\## Features



\- 💬 Real-time messaging over LAN

\- 👑 Admin panel with user management

\- 🎨 Modern, responsive UI design

\- 📱 Mobile-friendly interface

\- 🔒 Admin commands (kick, ban, clear)

\- 👥 Online users list

\- 🚀 Fast and lightweight



\## Admin Login



\- \*\*Username:\*\* `admin`

\- \*\*Password:\*\* `admin123`



\## Admin Commands



\- `/kick username` - Kick a user

\- `/ban username` - Ban a user  

\- `/clear` - Clear all messages

\- `/users` - Show online users
