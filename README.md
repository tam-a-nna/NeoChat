## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 **Real-time Chat** | Instant messaging over Local Area Network |
| 🎨 **Modern UI** | Beautiful gradient design with smooth animations |
| 👑 **Admin Panel** | Complete admin control with secure login |
| 📱 **Responsive** | Works perfectly on mobile, tablet, and desktop |
| 👥 **User Management** | Online users list with status indicators |
| 🔒 **Security** | Admin-only commands, user kicking and banning |
| 🚀 **Lightweight** | Zero external dependencies - pure Python! |
| 🌐 **Cross-platform** | Works on Windows, Linux, and macOS |
| ✨ **Animations** | Smooth message slide-in and fade effects |
| 🎯 **User-friendly** | Simple interface, easy to use |

## 🚀 Quick Start

### Prerequisites
- **Python 3.7** or higher
- No additional packages needed!

### Installation

```bash
# Clone the repository
git clone https://github.com/tam-a-nna/NeoChat.git

# Navigate to folder
cd NeoChat

# Run the server
python working_chat.py
